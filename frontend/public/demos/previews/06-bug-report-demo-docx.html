BUG-001 — Mobile Login Button Not Responding

Steps to Reproduce

Open the demo website on a mobile browser.

Navigate to the Login page.

Enter valid demo credentials.

Tap the Login button.

Observe that no action occurs.

Expected Result

The login request should be submitted and the user should be redirected to the authenticated area.

Actual Result

The button appears clickable, but no visible action occurs.

Recommended Investigation

Check mobile click handlers, form submission events, browser console errors and responsive overlay elements.
